# Xiaoxiang Realm Expansion 0.0.2-alpha

### *Not yet released.*

**This version is not public, and is not ready to be.**

Realm Expansion extends the cultivation ladder itself, which means it has to
match the base mod's own realm framework exactly — and that framework is still
being worked on by its creator. Extending a moving target would produce
a mod that breaks on the next base-mod update, and an expansion that breaks
your save is worse than one that arrives later.

So this is deliberately held. Development resumes once the final framework is
settled.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## What exists so far

- The mod loads alongside Xiaoxiang Cultivation World and registers cleanly
- Layer-state scaffolding for the extended realm structure
- Config surface designed to be driven by **Xiaoxiang Config Extension**, so
  every value it adds is tunable rather than fixed
