# ⛰️ Xiaoxiang Realm Expansion

An expansion for **Xiaoxiang Cultivation World**: ten layers to every
cultivation realm (nine to Mortal), every requirement yours to set, spiritual
water in seven grades with everything it steeps, wild cultivators who climb as
you do, flight, and - with Cosmic Horizons - the doors between a planet and
space, with the Xiao Universe growing behind them.

**📥 Download on CurseForge → https://www.curseforge.com/minecraft/mc-mods/xiaoxiang-realm-expansion**

## Requirements

- Minecraft **1.20.1**
- Forge **47.x**
- **Xiaoxiang Cultivation World** - required; this mod does nothing without it
- *(optional)* **Xiaoxiang Config Extension** - every setting of this mod on a
  proper in-game screen, with an explanation on each
- *(optional)* **Cosmic Horizons** - the universe features need it

## How it works

**No file belonging to Xiaoxiang Cultivation World is ever modified.** Everything
is applied at runtime, and the mod can be removed at any time with no lasting
effect on a save.

## What is in this repository

The release notes for every version, the licence, and the jar of the
current release under `release/`. The notes say, for every version, what is
new, what changed, what was fixed, what is in but not finished, and what you may
run into.
